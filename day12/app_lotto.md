# 로또 번호 생성기 PRD

- 작성일: 2026-10-06
- 대상: 이 문서를 읽고 구현할 Claude Code
- 작업 폴더: `day12/mylotto/`

## 1. 개요

로또 6/45 번호를 5세트씩 랜덤으로 만들어 주는 웹 앱이다.
사용자는 꼭 넣고 싶은 번호(고정)와 빼고 싶은 번호(제외)를 직접 고를 수 있다.

## 2. 기술 조건

| 항목 | 내용 |
| --- | --- |
| 화면 | HTML / CSS / JavaScript (프레임워크, 빌드 도구, 서버 없음) |
| 디자인 | Bootstrap 5.3.3 + Bootstrap Icons 1.11.3 (CDN, `day10/weather.html`과 같은 방식) |
| 파일 분리 | HTML, CSS, JS를 각각 별도 파일로 작성. HTML 안에 `<style>`, 인라인 `<script>` 코드를 두지 않는다 |
| 실행 | `index.html`을 브라우저에서 바로 열면 동작한다 |
| 언어 | 화면 문구는 모두 한국어, `<html lang="ko">` |

### 파일 구조

```
day12/
├── app_lotto.md        이 문서 (PRD)
└── mylotto/
    ├── index.html      화면 구조
    ├── css/
    │   └── style.css   Bootstrap으로 안 되는 부분만 (로또 공, 번호판 상태 색)
    └── js/
        └── app.js      번호 선택, 번호 생성
```

## 3. 화면 구성

한 페이지, 위에서 아래로 네 영역. 가운데 정렬된 한 칼럼(`col-12 col-lg-10`).

1. 제목: "로또 번호 생성기"
2. 번호 선택 영역: 좌우 2분할
   - 왼쪽 카드 "고정할 번호": 1~45 번호판
   - 오른쪽 카드 "제외할 번호": 1~45 번호판
3. "번호 생성" 버튼, "전체 초기화" 버튼
4. 생성 결과 카드 (A~E 5세트). 카드 제목 오른쪽에 "결과 지우기" 버튼, 세트마다 줄 오른쪽 끝에 복사 버튼

```
┌──────────────────────────────────────────┐
│            로또 번호 생성기              │
├────────────────────┬─────────────────────┤
│ 고정할 번호   n/6  │ 제외할 번호   n개   │
│ [1][2][3] ... [7]  │ [1][2][3] ... [7]   │
│ ...                │ ...                 │
│ [43][44][45]       │ [43][44][45]        │
├────────────────────┴─────────────────────┤
│ [    번호 생성 (5세트)    ] [전체 초기화]│
├──────────────────────────────────────────┤
│ 생성 결과                  [결과 지우기] │
│ A  ● ● ● ● ● ●                    [복사] │
│ ...                                      │
│ E  ● ● ● ● ● ●                    [복사] │
└──────────────────────────────────────────┘
```

- 두 카드는 `col-md-6`씩 나란히 놓는다. 화면 폭이 좁으면(md 미만) 고정 카드가 위, 제외 카드가 아래로 쌓인다.
- 각 번호판은 7칸 격자(7줄, 마지막 줄은 3칸).
- 각 카드 제목 오른쪽에 개수를 표시한다: 고정 "n/6", 제외 "n개".

### 로또 공 색상 (생성 결과에 적용)

| 번호 | 색 |
| --- | --- |
| 1~10 | 노랑 `#fbc400` |
| 11~20 | 파랑 `#69c8f2` |
| 21~30 | 빨강 `#ff7272` |
| 31~40 | 회색 `#aaaaaa` |
| 41~45 | 초록 `#b0d840` |

공은 원형, 숫자는 가운데 정렬, 굵은 글씨.

## 4. 기능 요구사항

### F1. 번호 생성

- "번호 생성" 버튼을 누르면 5세트(A~E)를 한 번에 만든다. 다시 누르면 5세트 전체를 새로 만든다.
- 각 세트는 1~45 중 서로 다른 번호 6개이고, 오름차순으로 표시한다.
- 고정 번호(F2)는 5세트 모두에 들어간다. 나머지 자리는 고정도 제외도 아닌 번호 중에서 랜덤으로 채운다.
- 제외 번호(F3)는 어떤 세트에도 나오지 않는다.
- 페이지를 처음 열었을 때는 결과 영역에 "번호 생성 버튼을 눌러 주세요." 안내만 보인다.
- 고정 번호가 6개면 5세트가 모두 같은 번호가 된다. 이 경우는 그대로 허용한다.

### F1-1. 세트별 번호 복사

- 생성 결과의 각 세트 줄 오른쪽 끝에 복사 버튼(클립보드 아이콘)을 둔다.
- 누르면 그 세트의 번호 6개를 `1, 13, 18, 26, 34, 38` 형식의 글자로 클립보드에 복사한다.
- 복사에 성공하면 버튼이 1.5초 동안 초록색 체크 표시로, 실패하면 빨간색 X 표시로 바뀌었다가 원래대로 돌아온다.

### F2. 수동 선택 (고정 번호, 왼쪽 번호판)

- 번호를 누르면 고정 번호가 된다. 다시 누르면 해제된다.
- 최대 6개. 7번째를 누르면 선택되지 않고 "고정 번호는 6개까지 선택할 수 있어요." 문구를 왼쪽 카드 아래쪽에 보여 준다.
- 선택된 번호는 파란 계열(Bootstrap `primary`)로 표시한다.

### F3. 제외 번호 (오른쪽 번호판)

- 번호를 누르면 제외 번호가 된다. 다시 누르면 해제된다.
- 제외하고 남는 번호가 6개 이상이어야 하므로 최대 39개. 넘으면 "남은 번호가 6개 이상이어야 해요." 문구를 오른쪽 카드 아래쪽에 보여 준다.
- 선택된 번호는 빨간 계열(Bootstrap `danger`) + 취소선으로 표시한다.

### F2, F3 공통 규칙

- 번호 하나는 "기본 / 고정 / 제외" 중 한 상태만 가진다.
- 한쪽 번호판에서 선택된 번호는 반대쪽 번호판에서 비활성(흐리게, 클릭 불가)으로 표시한다. 한쪽에서 해제하면 반대쪽에서 다시 누를 수 있다.
- 안내 문구는 다음에 번호를 정상적으로 선택하거나 해제하면 사라진다.
- "전체 초기화" 버튼은 고정, 제외 선택과 안내 문구를 모두 지운다. 생성 결과도 처음 안내 문구 상태로 돌린다.
- 생성 결과 카드의 "결과 지우기" 버튼은 생성 결과만 처음 안내 문구 상태로 돌리고, 고정/제외 선택은 그대로 둔다. 결과가 없을 때는 비활성이다.

## 5. app.js 구현 지침

- 상태는 번호별 상태 배열(기본/고정/제외) 하나만 둔다. 두 번호판은 이 배열 하나를 같이 본다.
- 상태가 바뀔 때마다 두 번호판과 개수 표시를 다시 그리는 함수 하나로 처리한다.
- 번호판 버튼 90개(45 × 2)는 HTML에 직접 쓰지 말고 JS 반복문으로 만든다.
- 번호 뽑기: 후보 배열(고정, 제외를 뺀 번호)을 섞어서 앞에서부터 필요한 개수만큼 꺼낸다.
- 이벤트는 `addEventListener`로 연결한다. HTML에 `onclick` 속성을 쓰지 않는다.
- 복사 버튼은 생성할 때마다 새로 만들어지므로, 결과 영역에 클릭 이벤트를 한 번만 걸어 처리한다. 복사할 글자는 버튼의 `data-numbers` 속성에 담는다.
- 복사는 `navigator.clipboard.writeText`를 쓰고, 실패하면 임시 `textarea` + `document.execCommand("copy")`로 다시 시도한다.
- 수업 예제 수준에 맞춰 읽기 쉬운 코드로 작성하고, 한국어 주석을 단다.

## 6. 범위 밖

- 지난 회차 당첨번호 표시 (가져오기 어려워 제외하기로 결정)

- 당첨 여부 비교, 통계
- 로그인, 배포

## 7. 완료 확인 항목

1. `index.html`을 브라우저에서 직접 열면 화면이 뜨고 콘솔에 오류가 없다.
2. 넓은 화면에서 고정 번호판과 제외 번호판이 좌우로 나란히 보인다.
3. "번호 생성"을 누르면 5세트가 나오고, 각 세트는 중복 없는 6개 번호가 오름차순이다.
4. 고정 번호 2개를 고르고 생성하면 5세트 모두에 그 2개가 들어 있다.
5. 제외 번호를 고르고 여러 번 생성해도 그 번호가 한 번도 나오지 않는다.
6. 왼쪽에서 고른 번호는 오른쪽에서 눌러지지 않고, 반대도 같다.
7. 고정 7번째, 제외 40번째를 누르면 선택되지 않고 안내 문구가 나온다.
8. "전체 초기화"를 누르면 선택과 결과가 모두 처음 상태로 돌아간다.
9. HTML 파일에 `<style>`, 인라인 스크립트, `onclick` 속성이 없다.
10. 브라우저 폭 375px에서 두 번호판이 위아래로 쌓이고 가로 스크롤이 없다.
11. "결과 지우기"를 누르면 결과만 사라지고 고정/제외 선택은 그대로 남는다.
12. 세트의 복사 버튼을 누른 뒤 메모장에 붙여 넣으면 그 세트의 번호 6개가 `1, 13, 18, 26, 34, 38` 형식으로 나온다.
