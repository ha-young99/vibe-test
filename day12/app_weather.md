# 날씨 앱 PRD

## 1. 개요

한국 도시와 세계 주요 도시의 현재 날씨와 향후 7일 예보를 보여주는 단일 페이지 웹앱.

- 기술: HTML / CSS / JavaScript (프레임워크, 빌드 도구 없음)
- 디자인: Bootstrap 5 (CDN), 아이콘은 Bootstrap Icons (CDN)
- 데이터: Open-Meteo API (무료, 가입과 API 키 불필요)
- 실행: `index.html`을 브라우저에서 바로 열면 동작해야 한다

## 2. 파일 구조

HTML, CSS, JS는 반드시 분리한다. HTML 안에 인라인 `<style>`, 인라인 `<script>` 코드, `onclick` 속성을 쓰지 않는다.

```
day12/
├── index.html      화면 뼈대 (네비바, 탭, 카드 영역, 모달)
├── css/
│   └── style.css   Bootstrap으로 부족한 부분만 보완
└── js/
    ├── cities.js   도시 목록 데이터 (이름, 위도, 경도)
    └── app.js      API 호출, 렌더링, 이벤트 처리
```

`file://`로 열어도 동작하도록 ES 모듈(`type="module"`)을 쓰지 않고 일반 `<script src>`로 `cities.js` → `app.js` 순서로 불러온다.

## 4. 화면 구성

### 4.1 메인 화면

1. **상단 네비바**: 앱 이름, 도시 검색창, 새로고침 버튼
2. **탭**: `한국 도시` / `세계 주요 도시` (Bootstrap nav-pills). 기본 선택은 `한국 도시`
3. **도시 카드 그리드**: Bootstrap grid 사용. 모바일 2열, 태블릿 3열, 데스크톱 4열
4. **마지막 갱신 시각**: 카드 영역 아래에 작게 표시

### 4.2 도시 카드

각 카드에 다음을 표시한다.

- 도시 이름, 날씨 아이콘
- 현재 온도 (°C, 정수로 반올림)
- 풍속 (km/h)과 풍향 (8방위 한글: 북, 북동, 동, 남동, 남, 남서, 서, 북서)
- 습도 (%)
- **비가 올 때만** 강수 배지: `비 70% · 4.2 mm` (오늘의 강수확률과 강수량)

카드 전체가 클릭 영역이며, 클릭하면 해당 도시의 7일 예보 모달이 열린다.

### 4.3 7일 예보 모달 (Bootstrap Modal)

- 제목: `{도시명} · 7일 예보`
- 현재 날씨 요약 4칸: 현재 온도, 풍속, 풍향, 습도
- 요일별 예보 7행 (첫 행은 `오늘`, 이후는 요일 한 글자)

| 열 | 내용 |
| --- | --- |
| 요일 | 오늘, 수, 목 … |
| 날씨 | 아이콘 + 한글 설명 |
| 기온 | 최저 / 최고 (°C) |
| 강수 | 비가 오는 날: 강수확률(%) + 강수량(mm) 배지. 그 외: 강수확률만 회색 글씨 |
| 바람 | 최대 풍속 (km/h) + 풍향 |

### 4.4 디자인 방향

흰 카드와 얇은 테두리의 깔끔한 배치를 기본으로 하고, 아이콘과 숫자, 배지에만 색을 넣어 포인트를 준다. 카드 배경 전체를 색으로 채우지 않는다. 색은 `style.css`의 CSS 변수로 정의하고 JS는 날씨 그룹에 맞는 클래스만 붙인다.

**날씨 그룹별 색상**

| 그룹 | 클래스 | 아이콘 원 배경 | 아이콘 | 온도 숫자, 예보 아이콘 |
| --- | --- | --- | --- | --- |
| 맑음, 구름 조금 | `weather-sunny` | `#FAEEDA` | `#BA7517` | `#EF9F27` |
| 흐림, 안개 | `weather-cloudy` | `#F1EFE8` | `#5F5E5A` | `#888780` |
| 이슬비, 비, 소나기, 눈 | `weather-rainy` | `#E6F1FB` | `#185FA5` | `#378ADD` |
| 뇌우 | `weather-storm` | `#EEEDFE` | `#534AB7` | `#7F77DD` |

**구성 요소**

- **네비바**: 흰 배경. 앱 이름 앞에 파란 원(`#185FA5`) 안의 흰 구름 아이콘. 새로고침 아이콘은 파란색(`#378ADD`)
- **탭**: 선택된 탭은 파란 배경(`#185FA5`)에 밝은 글자, 나머지는 테두리만
- **도시 카드**: 흰 배경, 얇은 테두리, 모서리 12px. 오른쪽 위에 날씨 그룹 색의 원형 아이콘, 온도 숫자는 날씨 그룹 색. 바람 아이콘은 청록(`#1D9E75`), 습도 아이콘은 파랑(`#378ADD`). 마우스를 올리면 테두리가 파란색(`#378ADD`)으로 바뀐다
- **강수 배지**: 연한 파란 배경(`#E6F1FB`)에 진한 파란 글자(`#0C447C`)
- **모달 요약 4칸**: 칸마다 다른 연한 색 배경을 쓴다. 현재 온도는 코랄(`#FAECE7` / 글자 `#712B13`), 풍속은 청록(`#E1F5EE` / `#085041`), 풍향은 보라(`#EEEDFE` / `#3C3489`), 습도는 파랑(`#E6F1FB` / `#0C447C`)
- **예보 행**: 날씨 아이콘은 날씨 그룹 색, 최저 기온은 파랑(`#378ADD`), 최고 기온은 코랄(`#D85A30`)
- **글자와 배경 대비**: 색 배경 위 글자는 같은 계열의 진한 색을 쓴다

## 5. 기능 요구사항

| ID | 요구사항 |
| --- | --- |
| F1 | 페이지 로드 시 전체 도시의 날씨를 불러와 카드로 표시한다 |
| F2 | 탭을 누르면 해당 그룹의 도시만 보인다 (추가 API 호출 없음) |
| F3 | 검색창에 입력하면 현재 탭 안에서 도시 이름으로 즉시 필터링한다. 결과가 없으면 "일치하는 도시가 없습니다."를 표시한다 |
| F4 | 카드를 클릭하면 7일 예보 모달이 열린다 (이미 받아둔 데이터 사용, 추가 호출 없음) |
| F5 | 새로고침 버튼을 누르면 데이터를 다시 불러오고 갱신 시각을 바꾼다 |
| F6 | 비 예보가 있으면 강수확률(%)과 강수량(mm)을 함께 표시한다 |
| F7 | 풍속은 항상 km/h 단위로 표시한다 |
| F8 | 로딩 중에는 Bootstrap spinner를, 실패 시에는 안내 문구와 `다시 시도` 버튼을 표시한다 |

### 비가 온다의 기준

- 카드/예보 행의 강수 배지 표시 조건: 해당 날짜의 `precipitation_sum > 0` **또는** `precipitation_probability_max >= 30`
- 강수량이 0이면 배지에 확률만 표시한다 (`비 40%`)

## 6. 데이터 (Open-Meteo)

### 요청

전체 도시를 **한 번의 요청**으로 가져온다. `latitude`, `longitude`에 쉼표로 여러 좌표를 넣으면 응답이 같은 순서의 배열로 온다.

```
GET https://api.open-meteo.com/v1/forecast
  ?latitude=37.5665,35.1796,...
  &longitude=126.9780,129.0756,...
  &current=temperature_2m,relative_humidity_2m,wind_speed_10m,wind_direction_10m,precipitation,weather_code
  &daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_sum,precipitation_probability_max,wind_speed_10m_max,wind_direction_10m_dominant
  &wind_speed_unit=kmh
  &timezone=auto
  &forecast_days=7
```

### 필드 매핑

| 화면 항목 | API 필드 |
| --- | --- |
| 현재 온도 | `current.temperature_2m` |
| 습도 | `current.relative_humidity_2m` |
| 풍속 | `current.wind_speed_10m` |
| 풍향 | `current.wind_direction_10m` (도 → 8방위 변환) |
| 현재 날씨 아이콘 | `current.weather_code` |
| 일별 최고/최저 | `daily.temperature_2m_max` / `daily.temperature_2m_min` |
| 일별 강수량 | `daily.precipitation_sum` (mm) |
| 일별 강수확률 | `daily.precipitation_probability_max` (%) |
| 일별 바람 | `daily.wind_speed_10m_max`, `daily.wind_direction_10m_dominant` |

### 풍향 변환

`Math.round(deg / 45) % 8`을 인덱스로 `["북", "북동", "동", "남동", "남", "남서", "서", "북서"]`에서 고른다.

### 날씨 코드 (WMO) 매핑

| 코드 | 설명 | Bootstrap Icon |
| --- | --- | --- |
| 0 | 맑음 | `bi-sun` |
| 1, 2 | 구름 조금 | `bi-cloud-sun` |
| 3 | 흐림 | `bi-clouds` |
| 45, 48 | 안개 | `bi-cloud-fog` |
| 51, 53, 55, 56, 57 | 이슬비 | `bi-cloud-drizzle` |
| 61, 63, 65, 66, 67 | 비 | `bi-cloud-rain` |
| 71, 73, 75, 77 | 눈 | `bi-cloud-snow` |

목록에 없는 코드는 `흐림`으로 처리한다.

## 7. 비기능 요구사항

- 반응형: 375px 폭에서도 가로 스크롤 없이 보여야 한다
- 모든 문구는 한국어
- 숫자 표기: 온도는 정수, 풍속은 정수, 강수량은 소수 첫째 자리
- API 응답 값은 `textContent`로 넣는다 (`innerHTML`에 직접 넣지 않는다)
- 외부 의존성은 Bootstrap 5 CSS/JS와 Bootstrap Icons CDN뿐이다
- API 키, 회원가입, 설정 파일이 필요 없어야 한다
